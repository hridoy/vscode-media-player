# Video Autoplay Extension

Automatically plays video files in the current folder one after another.

## Features

- **Context Menu Play**: Right-click on any video file and select "Play Video Playlist Here" to start playing videos from that file onwards in the current folder.
- **Recursive Play**: Use the "Play All Videos" command to scan the entire workspace for videos.

## Requirements

VSCode 1.80.0 or higher.
